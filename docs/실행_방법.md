# 실행 방법

모든 명령은 **저장소 맨 위 폴더**(`delay-check/`)에서 실행합니다. `.streamlit/` 설정이 이 위치에서 읽혀요.

## A. 내 PC

1. Python 3.11~3.12 설치 (python.org, 설치할 때 "Add to PATH" 체크)
2. 가상환경을 만들고 라이브러리 설치:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements-dev.txt
   ```
   (`requirements-dev.txt` = 앱 라이브러리 + 테스트용 pytest. 앱만 돌릴 거면 `requirements.txt`도 돼요)
3. `.streamlit/secrets.toml.example`을 복사해 이름을 `secrets.toml`로 바꾸고, 공공데이터포털 **일반 인증키(Decoding)** 넣기
   - 키가 없어도 앱은 열려요. 이때 날씨는 그 달의 평균값으로 계산됩니다.
4. 실행:
   ```
   streamlit run app/main.py
   ```
   브라우저가 자동으로 열려요 (http://localhost:8501)

## B. Streamlit Community Cloud (무료, 설치 없음)

1. GitHub에 저장소 올리기 (`secrets.toml`, DB 파일은 `.gitignore`에 들어 있어서 올라가지 않아요)
2. https://share.streamlit.io 에서 GitHub로 로그인 → New app → 저장소 선택, **Main file path는 `app/main.py`**
3. Advanced settings → Python 3.12 선택, Secrets 칸에 `KMA_SERVICE_KEY = "인증키"` 붙여넣기 → Deploy
4. ⚠️ Cloud는 앱이 재시작되면 `app/backend/data/` 안의 회원·기록이 지워질 수 있어요. 시연 영상용으로는 괜찮아요.

## 테스트

```
pip install -r requirements-dev.txt
python -m pytest tests
```

- `tests/test_backend.py`: 강수 글자 → mm 변환, 발표 시각 계산, 회원가입·로그인·기록 10개 제한, 모델 예측·편 비교
- `tests/test_frontend.py`: 5개 화면이 오류 없이 그려지는지, 편명 조회 → 결과 / 없는 편명 화면으로 가는지 (API 키 없이 실행)

## 꼭 확인할 것: 라이브러리 버전

- 모델은 scikit-learn **1.6.1**, xgboost **3.4.1**로 저장돼 있어요. 두 버전 모두 `requirements.txt`에 고정해 두었어요.
- Streamlit도 **1.66.1**로 고정했어요. 코드가 쓰는 `use_container_width`, `components.html`이 새 버전에서 없어질 예정이라, 버전을 올리기 전에 코드부터 바꿔야 해요.
- 모델을 다시 만들면 Colab에서 아래를 실행해 나온 버전으로 `requirements.txt`를 맞추세요.
  ```python
  import sklearn, xgboost; print(sklearn.__version__, xgboost.__version__)
  ```
- **Windows에서 모델이 안 열리던 문제:** xgboost 3.4는 모델 안에 난수 상태(`rng_state`)를 저장하는데, 이 값의 형식이 Linux(Colab)와 Windows에서 달라요. 그래서 Colab 모델을 Windows에서 열면 `input stream corrupted` 오류가 났어요. `app/backend/model_loader.py`가 이 경우에만 값을 이 PC 형식으로 바꿔서 열어요. 모델 파일은 그대로 두고, 예측 결과도 달라지지 않아요.
- `requirements.txt`에는 한글을 쓰지 마세요. Windows의 pip가 cp949로 읽다가 오류가 나요.
